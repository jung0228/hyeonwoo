# 📘 [Dasgupta Ch 4 전수 풀이] 그래프 최단 경로, 다익스트라, 벨만-포드

## 1. 챕터 핵심 개념 요약

1. BFS (너비 우선 탐색):
   - 모든 간선의 가중치가 1일 때 최단 경로를 탐색합니다.
   - 큐(Queue) 자료구조를 사용하며 $O(|V| + |E|)$ 시간에 완료됩니다.

2. 다익스트라 (Dijkstra) 알고리즘:
   - 모든 간선 가중치가 0 이상(양수)일 때 사용합니다.
   - 우선순위 큐(Min-Heap)를 사용하여 가장 가까운 미방문 노드를 탐욕적(Greedy)으로 확정 짓습니다.
   - 이진 힙 기준 시간 복잡도는 $O((|V| + |E|) \log |V|)$ 입니다.

3. 벨만-포드 (Bellman-Ford) 알고리즘:
   - 음수 간선 가중치를 허용하며 단일 출발지 최단 경로를 구합니다.
   - 모든 간선에 대한 완화(Relaxation) 작업을 $|V| - 1$ 번 반복합니다.
   - 시간 복잡도는 $O(|V| \cdot |E|)$ 이며, $|V|$ 번째 완화 시에도 값이 줄어들면 음수 사이클(Negative Cycle)이 존재함을 판별합니다.

4. DAG (방향 비순환 그래프) 최단 경로:
   - 위상 정렬(Topological Sort) 순서대로 간선을 완화하여 $O(|V| + |E|)$ 선형 시간에 해결합니다.

[30초 직관]
출발점에서 가까운 노드부터 순서대로 최단 거리를 확정(방문)하고, 연결된 이웃 노드들의 거리를 갱신합니다.

[단계별 정밀 풀이]
1. 시작점 A를 dist[A] = 0 으로 두고 우선순위 큐에 삽입합니다.
2. 탐색 진행 순서:
   - Step 1: A(0) 확정 ➔ B=1, E=4, F=8 갱신
   - Step 2: B(1) 확정 ➔ C=3, F=7, G=7 갱신
   - Step 3: C(3) 확정 ➔ D=4, G=5 갱신

   - Step 6: G(5) 확정 ➔ F=6, H=6 갱신
   - Step 7: F(6) 확정 ➔ 갱신 없음
   - Step 8: H(6) 확정 ➔ 탐색 완료
3. 최종 거리 결과:
   - A: 0, B: 1, C: 3, D: 4, E: 4, F: 6, G: 5, H: 6

### 📌 Exercise 4.8 (음수 간선에 양수 상수 더하기 꼼수의 결함)
[원문 핵심]
모든 간선 가중치에 큰 양수 상수 C를 더해 양수로 변환한 뒤 다익스트라를 실행하는 방식이 왜 잘못되었는지 반례를 들어 증명하시오.

[30초 직관]
간선 개수가 많은 경로는 통행세(C)를 여러 번 지불하게 되어, 원래의 진짜 최단 경로가 불리해지는 왜곡이 발생합니다.

[단계별 정밀 풀이]
1. 경로 P의 변환 후 길이:
   $$L'(P) = \sum_{e \in P} (l_e + C) = L(P) + |P| \cdot C$$
   여기서 $|P|$ 는 경로에 포함된 간선의 개수입니다.
2. 반례 구성:
   - s -> t 직접 간선: 길이 -1 (간선 1개)
   - s -> u -> t 우회 경로: 길이 -2 + -2 = -4 (간선 2개)
   - 원래 최단 경로는 s -> u -> t (-4) 입니다.
3. 모든 간선에 C = 3 을 더한 경우:
   - s -> t 직접 간선 길이: -1 + 3 = 2
   - s -> u -> t 우회 경로 길이: 1 + 1 = 2
   - 만약 C = 10 을 더하면 직접 간선은 9, 우회 경로는 16이 되어 최단 경로가 뒤바뀝니다.
4. 결론: 간선 수 $|P|$ 가 서로 다른 경로 간에 가중치 왜곡이 발생하므로 타당하지 않습니다. $\blacksquare$

### 📌 Exercise 4.9 (출발점에서 나가는 간선만 음수일 때 다익스트라 정당성)
[원문 핵심]
출발점 s에서 나가는 간선들만 음수이고 나머지 모든 간선은 양수일 때, 다익스트라 알고리즘이 올바르게 동작함을 증명하시오.

[30초 직관]
첫 걸음에서 할인 쿠폰을 미리 받고 시작하는 것과 같으며, 이후에는 모든 간선이 양수이므로 거리가 단조증가하여 과거가 뒤엎어지지 않습니다.

[단계별 정밀 풀이]
1. 초기화 단계에서 s의 이웃 노드 v들은 $dist[v] = l(s, v)$ 로 설정됩니다 (음수 가능).
2. s 이후의 모든 간선 $e = (u, w)$ 는 $l(u, w) > 0$ 양수입니다.
3. 우선순위 큐에서 최소 거리 노드 u가 추출될 때, 큐에 남아있는 임의의 노드 z는 이미 $dist[z] \ge dist[u]$ 입니다.
4. z에서 출발하여 양수 간선들만을 거쳐 u에 도달하는 경로는 항상 $dist[z] + \text{양수} > dist[u]$ 이므로, u의 거리가 추후 더 작아지는 것은 불가능합니다.
5. 따라서 그리디 선택 속성(Greedy Choice Property)이 보존되어 최적해가 보장됩니다. $\blacksquare$

### 📌 Exercise 4.6 (다익스트라 prev 배열의 트리 성질 증명)
[원문 핵심]
다익스트라 알고리즘이 생성하는 {u, prev[u]} 간선들의 집합이 항상 트리(Tree)를 형성함을 증명하시오.

[30초 직관]
모든 간선 완화는 거리가 더 작은 부모에서 더 큰 자식 방향으로만 연결되므로, 사이클이 생기는 것은 수학적으로 불가능합니다.

[단계별 정밀 풀이]
1. 정점 집합 V에 대해 간선의 수는 정확히 $|V| - 1$ 개입니다 (시작점 s를 제외한 각 정점이 정확히 하나의 prev 부모를 가짐).
2. 사이클 비존재 증명 (귀류법):
   - prev 간선들로 이루어진 사이클 $v_1 \to v_2 \to \dots \to v_k \to v_1$ 이 존재한다고 가정합니다.
   - 간선 완화 조건에 의해 $dist[v_{i}] > dist[v_{i-1}]$ (모든 간선 가중치 $l_e > 0$) 가 성립합니다.
   - 사이클을 따라 합산하면 $dist[v_1] > dist[v_k] > \dots > dist[v_1]$ 이 되어 $dist[v_1] > dist[v_1]$ 이라는 모순이 발생합니다.
3. 연결성: s에서 도달 가능한 모든 정점은 s를 루트로 하는 경로를 가집니다.
4. 따라서 prev 간선 집합은 루트가 s인 유향 트리(Directed Tree)를 이룹니다. $\blacksquare$

### 📌 Exercise 4.5 (두 노드 사이의 최단 경로 개수 계산)
[원문 핵심]
단위 가중치 무방향 그래프에서 노드 u에서 v로 가는 서로 다른 최단 경로의 총 개수를 $O(|V| + |E|)$ 시간에 구하시오.

[30초 직관]
BFS를 돌리면서 동적 계획법(DP)을 결합합니다. 나에게 최단 거리로 도달하는 이전 노드들의 경로 개수를 합산합니다.

[단계별 정밀 풀이]
1. 배열 정의:
   - dist[x]: u에서 x까지의 최단 거리 (초기값 무한대, dist[u] = 0)
   - count[x]: u에서 x까지의 최단 경로 개수 (초기값 0, count[u] = 1)
2. BFS 탐색 및 갱신 규칙:
   - 큐에서 정점 x를 꺼내 이웃 정점 y를 탐색합니다.
   - Case 1: dist[y] == 무한대 (y를 최초 방문)
     - dist[y] = dist[x] + 1
     - count[y] = count[x]
     - 큐에 y 삽입
   - Case 2: dist[y] == dist[x] + 1 (다른 최단 경로 발견)
     - count[y] = count[y] + count[x]
3. 시간 복잡도: 표준 BFS와 동일한 $O(|V| + |E|)$.

### 📌 Exercise 4.18 (동점 시 최소 간선 수 최단 경로 탐색)
[원문 핵심]
비용이 동일한 여러 최단 경로 중, 포함된 간선의 개수(환승 횟수)가 가장 적은 경로를 찾는 알고리즘을 설계하시오.

[30초 직관]
거리뿐만 아니라 간선 개수까지 2차원 우선순위 튜플 (거리, 간선수)로 관리하여 다익스트라를 수행합니다.

[단계별 정밀 풀이]
1. 상태 정의: 각 노드 u에 대해 (dist[u], best[u]) 쌍을 유지합니다.
   - dist[u]: s에서 u까지의 최소 가중치 합
   - best[u]: 최단 경로 상에서 사용된 최소 간선 개수
2. 완화(Relaxation) 규칙: 간선 (u, v)에 대해
   - 조건 1: dist[u] + l(u, v) < dist[v]
     - dist[v] = dist[u] + l(u, v)
     - best[v] = best[u] + 1
     - prev[v] = u
   - 조건 2: dist[u] + l(u, v) == dist[v] 이고 best[u] + 1 < best[v]
     - best[v] = best[u] + 1
     - prev[v] = u
3. 시간 복잡도: 우선순위 큐를 사용하는 다익스트라와 동일한 $O((|V| + |E|) \log |V|)$.

### 📌 Exercise 4.21 (외환 시장 차익 거래 Arbitrage)
[원문 핵심]
통화 간 환율 곱 $r_{1,2} \cdot r_{2,3} \cdots r_{k,1} > 1$ 이 되는 무위험 수익 사이클을 그래프 알고리즘으로 탐지하시오.

[30초 직관]
양변에 음의 로그(-log)를 취하면 환율의 곱셈 최대화 문제가 간선 가중치의 덧셈 최소화(음수 사이클 탐지) 문제로 변환됩니다.

[단계별 정밀 풀이]
1. 그래프 모델링:
   - 정점: 각 통화 $c_i$
   - 간선 가중치: $w(i, j) = - \ln(r_{i, j})$
2. 수학적 변환:
   $$\prod r > 1 \iff \ln(\prod r) > 0 \iff \sum \ln(r) > 0 \iff \sum (-\ln(r)) < 0$$
3. 알고리즘:
   - 변환된 그래프에서 벨만-포드(Bellman-Ford) 알고리즘을 실행합니다.
   - $|V| - 1$ 라운드 후 추가 1회 라운드에서 완화가 발생하는지 확인합니다.
   - 갱신이 발생하면 음수 사이클이 존재하며, 이는 환율 곱이 1을 초과하는 차익 거래 기회에 해당합니다.
4. 시간 복잡도: $O(|V| \cdot |E|)$.

### 📌 Exercise 4.16 (c) (`makeheap`의 $O(n)$ 선형 시간 증명)
[원문 핵심]
크기 n인 배열을 바닥부터 sift-down 방식으로 힙을 구성할 때, 전체 시간 복잡도가 $O(n)$ 선형 시간이 됨을 증명하시오.

[30초 직관]
노드가 많은 바닥 층은 이동 거리가 짧고(0~1칸), 이동 거리가 긴 꼭대기 층은 노드 수가 적어서 전체 합이 $O(n)$으로 수렴합니다.

[단계별 정밀 풀이]
1. 높이가 h인 포화 이진 트리에서 높이 k에 위치한 노드의 최대 개수는 $\lceil n / 2^{k+1} \rceil$ 개입니다.
2. 높이 k인 노드가 아래로 내려갈 수 있는 최대 거리는 k 입니다.
3. 총 연산량 합:
   $$T(n) = \sum_{k=1}^{\lfloor \log n \rfloor} \frac{n}{2^{k+1}} \cdot O(k) = O\left( n \sum_{k=1}^{\infty} \frac{k}{2^k} \right)$$
4. 멱급수 공식 $\sum_{k=1}^{\infty} \frac{k}{2^k} = 2$ 이므로:
   $$T(n) = O(n \cdot 2) = \mathbf{O(n)}$$
5. 따라서 바닥부터 빌드하는 `makeheap`의 시간 복잡도는 $O(n)$ 입니다. $\blacksquare$
