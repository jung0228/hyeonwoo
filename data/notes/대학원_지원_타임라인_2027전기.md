## 📅 핵심 타임라인 (예상)

| 기간 | 단계 | 할 일 |
|---|---|---|
| **8월 말 ~ 9/10** | 서류 준비 | 자기소개서 · 연구계획서 초안, 성적증명서/졸업증명서 발급, CV 갱신 |
| **9/14** | 인턴 입과 | 네이버클라우드 그린팩토리 인턴 시작 (병행) |
| **9월 중순** | 원서접수 준비 | 대학별 온라인 원서 작성, 사진/서류 스캔 |
| **9/20 ~ 10/14** | ⭐ 원서접수 | 대학별 원서 접수 (마감 확인 필수) |
| **10월 중순 ~ 11월** | 필기/면접 | 포스텍 필기시험(MML), 각 대학 면접, 교수 컨택 |
| **11월 ~ 12월** | 최종 발표 | 합격 통보, 등록 |

## 🎯 우선순위 액션 (이번 주)

- [ ] 대학 5곳 공식 모집요강 PDF 다운로드 → **정확한 원서접수 마감일** 기록
- [ ] 포스텍 필기시험 일정 확정 (가이드북 참조, 1인 1교수 컨택 원칙 유의)
- [ ] 자기소개서 + 연구계획서 **초안 1차 완성**
- [ ] 서울대 AIDAS(도재영) 면접 대비 시작 (컨택 완료 상태)
- [ ] 네이버 인턴 시작 전에 서류 마무리 (인턴 후에는 시간 부족)

---

## 📚 포스텍 필기시험 요약 (가이드북 참조)

- **형식**: 총 60분 = 기초수학 30분 + 알고리즘 30분
- **과목**: MML Ch2~7 + 알고리즘
- **기초수학 핵심**: Rank/Kernel/Image, SVD & Eigen 분해, Gradient/Jacobian/Hessian, 정사영·최소제곱, MLE vs MAP, 가우시안
- **알고리즘**: 기본 자료구조/알고리즘 문제
