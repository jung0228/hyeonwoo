# 📘 [Dasgupta Ch 5 전수 풀이] 탐욕법 (Greedy Algorithms) 골든 8선

## 1. 챕터 핵심 개념 요약

1. 최소 신장 트리 (MST, Minimum Spanning Tree):
   - 모든 노드를 연결하면서 사이클 없이 가중치 합을 최소화하는 부분 그래프 ($|V|-1$개 간선).
   - Cut Property: 임의의 컷을 가로지르는 최소 가중치 간선은 반드시 어떤 MST에 포함된다.
   - Cycle Property: 임의의 사이클에서 가장 무거운 간선은 어떤 MST에도 포함될 수 없다.

2. 크루스칼 (Kruskal) vs 프림 (Prim) 알고리즘:
   - 크루스칼: 전체 간선을 가중치 오름차순으로 정렬 후, 유니온-파인드(Disjoint Set)로 사이클 검사하며 채택 ($O(|E| \log |V|)$).
   - 프림: 임의의 한 노드에서 출발하여 현재 영토와 연결된 최소 간선을 우선순위 큐로 탐욕적 확장 ($O((|V| + |E|) \log |V|)$).

3. 유니온-파인드 (Disjoint Sets) 최적화:
   - Union by Rank: 높이가 낮은 트리를 높은 트리 밑에 붙여 트리 높이를 $O(\log n)$ 이하로 유지.
   - Path Compression: `find` 시 거쳐간 모든 노드를 루트에 직접 연결하여 실질적 $O(\alpha(n)) \approx O(1)$ 달성.

4. 허프만 코딩 (Huffman Encoding):
   - 빈도수가 높은 문자에는 짧은 비트, 낮은 문자에는 긴 비트를 할당하는 가변 길이 접두사(Prefix-free) 압축 기법 ($O(n \log n)$).

### 📌 Exercise 5.1 (크루스칼 손추적 & Cut 정당화)
[원문 핵심]
주어진 8개 노드 그래프에서 크루스칼 알고리즘을 수행하여 MST 비용, 가능한 서로 다른 MST 개수, 각 간선 추가 시의 정당화 컷(Cut)을 제시하시오.

[단계별 정밀 풀이]
1. (a) MST 총비용:
   - 선택된 간선: $(A,E)=1, (E,F)=1, (B,E)=2, (F,G)=3, (G,H)=3, (C,G)=4, (D,G)=5$
   - 총비용 = $1 + 1 + 2 + 3 + 3 + 4 + 5 = \mathbf{19}$
2. (b) 서로 다른 MST 개수:
   - 노드 B를 연결할 때 $(B,E)=2$ 와 $(B,F)=2$ 중 어느 것을 골라도 비용 19로 동일하므로 **총 2개**.
3. (c) 간선별 정당화 컷:
   - $(A,E)$: 컷 $S=\{A\}$ 에서 최소 간선
   - $(E,F)$: 컷 $S=\{A, E\}$ 에서 최소 간선
   - $(B,E)$: 컷 $S=\{B\}$ 에서 최소 간선
   - $(F,G)$: 컷 $S=\{A, B, E, F\}$ 에서 최소 간선
   - $(G,H)$: 컷 $S=\{H\}$ 에서 최소 간선
   - $(C,G)$: 컷 $S=\{C\}$ 에서 최소 간선
   - $(D,G)$: 컷 $S=\{D\}$ 에서 최소 간선

### 📌 Exercise 5.5 (모든 간선 가중치에 +1을 더할 때 MST vs 최단 경로 비교)
[원문 핵심]
모든 간선 가중치에 1을 더해 $w'_e = w_e + 1$ 이 되었을 때, (a) MST가 바뀌는가? (b) 최단 경로가 바뀌는가?

[단계별 정밀 풀이]
1. (a) 최소 신장 트리는 절대 바뀌지 않는다 (Cannot change):
   - 모든 스패닝 트리는 정확히 $|V|-1$개의 간선을 가지므로, 모든 트리의 총비용이 공평하게 $(|V|-1)$ 만큼만 증가하여 순위가 불변한다.
2. (b) 최단 경로는 바뀔 수 있다 (Can change):
   - 경로마다 포함된 간선 개수 $k$가 다르므로, $k$가 큰 경로는 더 큰 가중치($k \cdot 1$) 패널티를 받는다.
   - 반례: 간선 2개짜리 경로($0+0=0 \to 1+1=2$)와 간선 1개짜리 경로($1 \to 2$) 비교 시 간선 수가 많은 경로가 불리해져 역전 가능.

### 📌 Exercise 5.6 (가중치가 모두 다를 때 MST 유일성 증명)
[원문 핵심]
모든 간선 가중치가 서로 다르면(distinct), MST는 오직 유일하게 하나만 존재함을 증명하시오.

[단계별 정밀 풀이]
1. 서로 다른 두 MST $T_1, T_2$가 존재한다고 가정 (귀류법).
2. $T_1 \setminus T_2$ 에 속한 간선 중 가장 가중치가 작은 간선 $e$를 선택.
3. $T_2$에 $e$를 추가하면 사이클 $C$가 생기며, $C$ 상에는 $T_2 \setminus T_1$ 에 속한 간선 $e'$가 존재.
4. 모든 가중치가 다르므로 $w(e) < w(e')$ 이 성립.
5. $T_2$에서 $e'$를 빼고 $e$를 넣으면 $w(T_3) < w(T_2)$ 인 더 작은 트리가 만들어져 모순 발생.
6. 따라서 MST는 오직 유일하다. $\blacksquare$

### 📌 Exercise 5.9 (MST 10대 참/거짓 OX 완벽 총정리)
[단계별 정밀 풀이]
- (a) 가장 비싼 간선은 MST에 절대 못 들어간다? ➔ **[X]** (외딴섬을 잇는 유일한 Bridge인 경우 필수 포함)
- (b) 사이클 안에서 가장 비싼 간선 e는 어떤 MST에도 못 들어간다? ➔ **[O]** (Cycle Property)
- (c) 그래프 전체에서 가장 싼 간선 e는 어떤 MST에 반드시 포함된다? ➔ **[O]** (크루스칼 1순위 채택)
- (d) 가장 싼 간선이 유일하면 모든 MST에 반드시 들어간다? ➔ **[O]** (대체 불가능한 최솟값)
- (e) MST에 들어간 간선 e는 어떤 Cut에서 가장 싼 간선이다? ➔ **[O]** (Cut Property 역방향)
- (f) 사이클 안에서 가장 싼 간선 e는 모든 MST에 들어간다? ➔ **[X]** (외부 간선들이 더 싸면 사이클 내 최솟값도 탈락)
- (g) 다익스트라 최단 경로 트리는 MST이다? ➔ **[X]** (개별 최단거리 vs 전체 공사비 최소화 차이)
- (h) 두 노드 사이의 최단 경로는 반드시 어떤 MST의 일부이다? ➔ **[X]** (직통 고속도로가 비싸면 샛길 MST에서 제외)
- (i) 프림 알고리즘은 음수 간선이 있어도 올바르게 작동한다? ➔ **[O]** (누적 거리가 아닌 Cut 최솟값 비교이므로 유효)
- (j) G에 $s \to t$ 로 가는 $r$ 미만 경로가 있다면, 모든 MST에도 $r$ 미만 경로가 존재한다? ➔ **[O]** (MST가 우회하더라도 $\ge r$ 인 간선은 Cycle Property로 탈락하므로 모든 간선이 $< r$ 로 유지됨)

### 📌 Exercise 5.31 (총 대기 시간 최소화 작업 스케줄링)
[원문 핵심]
고객 $n$명의 처리 시간 $t_i$가 주어졌을 때 총 대기 시간을 최소화하는 알고리즘을 설계하고 증명하시오.

[단계별 정밀 풀이]
1. 알고리즘: 처리 시간 $t_i$를 오름차순(가장 짧은 순서)으로 정렬하여 처리 ($O(n \log n)$).
2. 정당성 증명:
   - 총 대기 시간 $T = \sum_{i=1}^n (n - i + 1)t_i = n \cdot t_1 + (n - 1)t_2 + \dots + 1 \cdot t_n$
   - 재배열 부등식에 의해 가장 큰 계수($n$)에 가장 작은 시간($t_1$)이 곱해질 때 총합 $T$가 최소화된다. $\blacksquare$
