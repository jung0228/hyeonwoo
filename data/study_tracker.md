- 2026-08-26:
  - **연구 논문 심층 분석 (온디바이스 실시간 멀티모달 토큰 압축 & 라우팅)**:
    1. **OmniSelect** (Dynamic Modality-Aware Token Compression for Efficient Omni-modal LLMs, 2025/2026)
       - **① Abstract 핵심**: 옴니모달 LLM(OmniLLM)의 시청각 토큰 폭증 문제를 해결하기 위해, 입력 쿼리에 따라 모달리티별 중요도를 동적으로 산정하여 차등 압축하는 학습 불필요(Training-free) 적응형 압축 프레임워크.
       - **② 방법 요약**: 경량화된 AudioCLIP으로 유저 쿼리와 시청각 모달리티 간 교차 관련도를 측정 $\to$ 3대 압축 체제(Audio-Centric, Video-Centric, Uniform) 동적 할당 $\to$ 시간 그룹 압축 파이프라인($\text{TGP}^2$)을 통해 오디오(어텐션 기반), 비디오(유사도 기반 $\text{Bottom-}K$) 토큰 프루닝.
       - **③ 한계점 (3대 관점)**:
         * *무질의(Query-Agnostic)*: 유저의 명시적 텍스트 질문이 반드시 주어져야 CLIP 점수 산출 가능 $\to$ 상시 모니터링/라이프로깅 환경에서 작동 불가.
         * *연속 스트리밍*: 전체 클립을 배치 단위로 처리하여 실시간 슬라이딩 윈도우 유입에 즉각적인 프레임별 압축 결정 한계.
         * *온디바이스 예산*: LLM 외 추가 AudioCLIP 인퍼런스 연산 오버헤드 존재, 디바이스의 발열/배터리/메모리 제약에 맞춘 동적 스케일링 부재.
       - **④ 한계 돌파 (내 연구 연결)**: 센서 레벨의 신호 엔트로피 및 음향 이벤트 감지(AED) 기반의 초경량 무질의 모달리티 라우터를 전단에 배치하여 텍스트 질의 없이도 하드웨어 예산 기반 실시간 라우팅 구현.
    2. **Multimodal Token Compression Survey** (TMLR 2026 / arXiv:2507.20198)
       - **① Abstract 핵심**: 이미지·비디오·오디오 전반의 롱컨텍스트 토큰 압축 기술을 데이터 모달리티(공간/시공간/스펙트럼 중복)와 메커니즘(변환/유사도/어텐션/질의 유도) 기준으로 체계화한 종합 서베이.
       - **② 방법 요약**: 인코더, 프로젝터, LLM 백본 등 적용 위치별 프루닝(Pruning), 머징(Merging), 변환(Q-Former 등) 기법을 정리하고 압축률 대비 정보 보존 트레이드오프 비교 분석.
       - **③ 한계점 (3대 관점)**:
         * *무질의(Query-Agnostic)*: 대다수 기법이 LLM 내부의 Query-to-Vision 어텐션 맵에 의존하여 질문 없는 대기 상태 대응 미비.
         * *연속 스트리밍*: 정적(Static) 파일 전제 위주이며, 실시간 무한 스트리밍 버퍼 및 KV 캐시 팽창 억제 방안 부족.
         * *온디바이스 예산*: 모바일 NPU 메모리 대역폭(BW) 한계, SRAM 크기, 비정형 프루닝의 하드웨어 가속 저하 문제 미해결.
       - **④ 한계 돌파 (내 연구 연결)**: 정적 입력을 탈피한 '스트리밍 2단계 계층형 압축 구조'(센서단 조기 필터링 + LLM 전단 교차모달 퓨전) 및 NPU 하드웨어 친화적 정형 블록 압축 제안.
    3. **ToMe** (Token Merging: Your ViT But Faster, ICLR 2023)
       - **① Abstract 핵심**: 추가 학습/파인튜닝 없이 Vision Transformer(ViT) 레이어 내부에서 유사한 토큰들을 점진적으로 병합(Merge)하여 속도를 비약적으로 향상시킨 범용 토큰 압축 기법.
       - **② 방법 요약**: 토큰 집합을 이분할(Bipartite matching) 후 Key 벡터 코사인 유사도가 가장 높은 상위 $r$개 토큰 쌍을 가중 평균으로 결합하여 레이어마다 토큰 $r$개씩 일정 감소.
       - **③ 한계점 (3대 관점)**:
         * *무질의(Query-Agnostic)*: 단일 모달리티 내 시각적 유사도만 고려하여, 배경처럼 보이지만 오디오 맥락상 중요한 핵심 토큰 손실 위험.
         * *연속 스트리밍*: 시공간(Spatio-Temporal) 프레임 간 중복성을 반영하지 않고 단일 프레임 내에서만 정적으로 병합.
         * *온디바이스 예산*: 고정된 $r$ 감축율로 인해 실시간 전력/메모리 상태나 프레임별 정보량 변화에 유연하게 대응 불가.
       - **④ 한계 돌파 (내 연구 연결)**: 오디오 에너지 및 이벤트 단서를 시각 토큰 병합 기준에 통합한 '시청각 교차 모달 토큰 머징' 및 하드웨어 리소스 연동 '가변 병합률($r_{\text{dyn}}$)' 도입.
    4. **FastV** (FastV: An Image is Worth 1/2 Tokens After Layer 2, CVPR 2024)
       - **① Abstract 핵심**: VLM의 초기 레이어(Layer 2) 이후 비주얼 토큰의 어텐션이 극도로 희소해짐을 규명하고, 하위 중요도 토큰의 50% 이상을 프루닝하여 연산량을 대폭 절감한 기법.
       - **② 방법 요약**: LLM 백본 2번째 레이어에서 텍스트/전체 토큰이 비주얼 토큰에 주는 어텐션 랭크를 계산하여 하위 $R\%$를 폐기, 남은 토큰으로 후속 레이어 순전파.
       - **③ 한계점 (3대 관점)**:
         * *무질의(Query-Agnostic)*: 유저 질문과의 어텐션 상호작용이 필수적이므로 질의 없는 상시 모니터링 스트림에서 프루닝 불가.
         * *연속 스트리밍*: 매 프레임마다 Layer 1~2의 전체 토큰 Full Prefill 연산을 강제하여 실시간 스트리밍 시 초기 레이어 병목 지속.
         * *온디바이스 예산*: LLM 본체 진입 후에야 토큰이 제거되므로 좁은 엣지 메모리 대역폭에서 비주얼 토큰 로드/캐싱 오버헤드가 잔존.
       - **④ 한계 돌파 (내 연구 연결)**: LLM 백본 진입 전(Pre-LLM Projector 레벨)에서 시청각 크로스 게이팅으로 조기 프루닝하여 LLM 메모리 대역폭 및 배터리 소모를 원천 차단.
