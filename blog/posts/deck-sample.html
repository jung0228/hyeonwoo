Self-Attention: input과 output의 정의

attention은 token 시퀀스를 받아 같은 길이의 문맥 반영 표현을 돌려준다. 핵심은 $K,V$가 input $X$만의 함수라는 점 — 뒤에서 캐싱이 성립하는 근거다.

input시퀀스 $X \in \mathbb{R}^{n \times d}$  (token $n$개, model dimension $d$)
projection$Q = XW_Q,\quad K = XW_K,\quad V = XW_V$  ($W_\bullet \in \mathbb{R}^{d\times d}$)
output$\mathrm{Attn}(X) = \mathrm{softmax}\!\left(\dfrac{QK^\top}{\sqrt{d}}\right)V \in \mathbb{R}^{n\times d}$
invariant$K,V$는 $X$에만 의존 — $Q$와 무관하게 token별로 한 번 결정된다.
03 / 09

문제: decoding은 invariant을 매번 다시 계산한다

autoregressive 생성은 token을 하나씩 만든다. step $t$의 input은 $x_1,\dots,x_t$, output은 $x_{t+1}$의 분포다. cache가 없으면 매 step $K_{1:t},V_{1:t}$ 전체를 다시 만든다.

재계산매 step $K_{1:t}=X_{1:t}W_K,\; V_{1:t}=X_{1:t}W_V$ 전부 다시 계산
낭비$k_i,v_i\ (i \lt t)$ 는 step이 바뀌어도 불변 — 재계산은 순수 낭비
step 비용projection $O(t\,d^2)$ + attention $O(t^2 d)$
전체$\sum_{t=1}^{n} \Rightarrow O(n^2 d^2) + \boxed{O(n^3 d)}$  — 길이의 3제곱
04 / 09

KV cache: 새 token만 계산하고 이어 붙인다

invariant $K,V$를 버리지 않고 cache에 보관한다. step $t$의 input은 cache $K_{\text{cache}},V_{\text{cache}}\in\mathbb{R}^{(t-1)\times d}$ 와 새 token $x_t$, output은 $o_t\in\mathbb{R}^{1\times d}$ 하나다.

① projection$q_t=x_tW_Q,\; k_t=x_tW_K,\; v_t=x_tW_V \in \mathbb{R}^{1\times d}$
② append$K_{\text{cache}}\!\leftarrow\![K_{\text{cache}};k_t],\;\; V_{\text{cache}}\!\leftarrow\![V_{\text{cache}};v_t]$  ($t\times d$)
③ attention$o_t=\mathrm{softmax}\!\left(\dfrac{q_t K_{\text{cache}}^\top}{\sqrt{d}}\right)V_{\text{cache}}$
핵심이전 token의 $k_i,v_i$는 0번 재계산 — cache에서 그대로 읽는다.
05 / 09

적용 조건: 어디서 성립하는가

KV cache는 만능이 아니다. 성립의 진짜 조건은 "$K,V$가 input에만 의존"이 아니라 causal masking — causal mask가 있어야 과거 token의 전 layer 표현이 미래 token에 영향받지 않아 $k_i,v_i$ 불변이 보장된다. bidirectional(encoder)에는 이 조건이 없다.

Attention 종류KV cache핵심 이유
Decoder self-attention · decode✓ 적용causal mask → token $i$ 표현은 $\le i$ 에만 의존; 새 token을 append해도 과거 $k,v$ 불변
Decoder · prefill (prompt)cache 적재prompt 전체를 1회 parallel 계산해 cache를 채우는 단계 (reuse 아님)
Encoder self-attention · bidirectional✗ 불가모든 token이 서로 attend·1회 parallel 처리; token 추가 시 전 표현이 바뀌고 생성 step도 없음
Cross-attention (encoder→decoder)✓ 강력$K,V$가 고정된 encoder output에서 옴 → 생성 내내 1회만 계산
06 / 09

step당 연산량: 무엇이 사라지는가

cache는 이전 token의 projection을 제거한다. step $t$ 기준으로 비교하면 — 새 token의 projection만 남고($O(d^2)$), attention은 cache 길이에 선형($O(td)$)이 된다.

step $t$ 비용cache 없음KV cache
이전 token $K,V$ 재계산$t-1$ 개 ($O(td^2)$)0 개
새 token projection $q_t,k_t,v_t$$O(d^2)$$O(d^2)$
attention $\mathrm{softmax}(qK^\top)V$$O(t^2 d)$$O(t\,d)$
전체 생성 ($t=1\dots n$)$O(n^3 d)$$O(n^2 d)$
07 / 09

대가: cache 메모리는 길이에 선형으로 늘어난다

연산은 줄지만 cache는 VRAM을 점유한다. 보관 원소 수는 token·layer·dimension·precision로 정확히 계산된다.

cache 크기 $= \underbrace{2}_{K,V}\cdot L \cdot n \cdot d_{\text{model}} \cdot b_{\text{bytes}} \cdot B_{\text{batch}}$
$L$ layer 수 · $n$ token 수 · $d_{\text{model}}$ dimension · $b$ precision(byte) · $B$ batch
시퀀스 길이 $n$, batch $B$ 에 정비례 → 긴 컨텍스트의 새 병목.
대응: MQA(K/V 헤드 1개), GQA(그룹 공유), PagedAttention(페이지 단위 관리).

구체 예시 — 7B급 model

layer $L$32
dimension $d_{\text{model}}$4096
token $n$8192
precisionfp16 = 2 B
batch $B$1
≈ 4.3 GB $2\cdot32\cdot8192\cdot4096\cdot2\,\text{B} = 4{,}294{,}967{,}296$ B
